# 水面、反射与接触反馈

## 按观看需求选择水体

将水组织为底面、覆盖/深浅、受光/反射、基础流动与接触反馈。先验证静水、岸边和遮挡，再加波动与互动。浅积水保留底纹，池塘强调岸边与较完整倒影，河流重视流向；平面画风也可只用少量色块与手绘反光。

水覆盖区域或遮罩同时用于视觉与交互，避免画面有水但脚步按干地处理。需要深度时明确来源，可用设计数据或地形计算；没有深度模拟的实现不能声称具备真实水深或浮力。

| 反射方式 | 选择依据与限制 |
| --- | --- |
| 手绘倒影、渐变或装饰投影 | 固定机位、低成本且可控；不会自动跟随物体和相机 |
| 环境图或探针 | 适合天空、远景与环境色；局部人物和近岸可能不准确，动态更新另有成本 |
| 平面反射 | 适合近似平坦水面；镜像相机额外渲染，需正确裁剪并排除水面本身 |
| 屏幕空间反射 | 复用当前画面的颜色与深度；屏幕外、遮挡与边缘信息缺失，需要回退 |

同高度、同朝向的水洼可评估共用平面反射与覆盖遮罩，不同平面不能直接共用同一个投影。反射采样来自反射相机变换，不是地面上的倒置截图；扰动按透视除法后的 UV 或等价齐次形式计算。

调整视口时同步反射相机、目标尺寸与纹素步长。半透明水面通常保留深度测试，再按管线处理写入与排序，检查水上人物、水下物件和岸边。标线、阴影与涟漪通过合理深度关系避免冲突，不大幅抬高水面来遮盖问题。

## 保持波纹与倒影稳定

- 基础波采用世界坐标或水体局部坐标，时间推进相位；河流可用流向坐标。不要把未除以 `w` 的投影坐标作为物理波相位，导致相机移动时水纹跟着滑。
- 细波小于屏幕可辨尺度时降低振幅。着色器可用片元导数估计像素足迹，`fwidth` 等导数应在一致的片元控制流中计算；不可用时按距离/屏幕尺寸渐减高频细节。
- 动态反射目标也需要缩小过滤；格式支持时，每次更新后生成 mipmap，评估额外存储与生成成本。静态贴图的过滤设置不会自动作用于反射目标。
- 细亮反射可做有界邻域过滤，核宽随反射纹素或投影足迹选择，避免整片变雾。这是粗糙反射近似，不自动等于物理粗糙度。
- 涟漪环宽按屏幕足迹柔化，随距离减弱并调节能量；不要仅把小于一像素的细环提亮，否则易成闪点。反射与辉光叠加时检查是否重复放大同一高光。
- 降低反射更新率可节约成本，但需检查相机运动时的滞后；优先在静止或远景采用。比较优化前后亮度、清晰度和动态表现，方法见[光影参考](lighting-stability.md)。

## 用同一个接触事件驱动效果

有角色时先按[像素素材参考](pixel-art.md)接入有效位移、动画触地标记与脚步事件。雨滴、落物、船行可用独立接触来源；不因为存在水面就强制增加角色或降雨。

```text
真实接触 → 查询覆盖、表面与接触强度 → 限制/合并过密事件
                                            ├─ 可见涟漪
                                            ├─ 倒影扰动
                                            ├─ 水珠、泡沫或尾迹
                                            └─ 按需声音
```

事件保存位置、法线、出生时间、接触类型及速度/冲量，人物另带左右脚与动作。涟漪与倒影扰动共享位置、时间和寿命；水珠可用初速度与重力轨迹，环半径随年龄增长、强度随年龄衰减。低帧率跨多个触地标记时，按各自事件时刻和沿途位置生成，避免全挤在最新落点。

步行采用低、小、短的反馈；跑步按真实速度、动作和湿度增加抛射、扩散与音量并设上限。跳跃落水按落地强度，船尾迹按相对水流速度，不能统一套跑步倍率。干地、撞墙、腾空不产生普通踩水反馈。

用有界事件池与粒子池控制寿命和数量，容量满时淘汰最旧或低优先级效果，保留主要交互的反馈。统一游戏时间，暂停冻结年龄，恢复时不补发整段缺失水花；瞬移与重置清理历史接触。

## 验收

按已有能力检查干湿过渡、走跑切换、静止与降雨、雨停后接触、物件进出、遮挡、暂停恢复及池容量上限。解析波纹与粒子属于视觉近似；流体碰撞、浮力与水流对角色的作用需要另行实现。
