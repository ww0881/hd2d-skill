# 像素素材与角色

## 尺度与绘制

用实际屏幕表现决定画布大小。小物件可从 16×16 或 32×32、地块从 32×32 或 64×64、人物从 32×48 起步；这些是试画尺寸，不是标准。

像素密度 `D = 表面有效像素数 / 对应世界长度`，横纵分别计算。宽 2、高 3 的墙若采用每单位 32 像素，可画成 64×96；更宽的墙使用更多有效像素或重复可平铺模块，避免拉伸。图集留白不计入有效像素；角色可有意使用不同密度，但需同屏比较。

用现有像素编辑器或可复现绘图脚本制作；不依赖特定软件。绘制使用硬边铅笔、整数坐标和不带抗锯齿的填充，按以下顺序推进：

1. **剪影**：单色确定类别、比例与主要负空间。
2. **大色块**：划分部件，先保证缩小后可读。
3. **明暗组**：每种主要材质先试三到五档明度，以少量偏色丰富层次；最高亮度与饱和度留给焦点。
4. **材质特征**：按结构画木纹、石面、褶皱或金属转折；磨损集中在接触与使用位置，避免均匀噪点。
5. **边缘整理**：修正断裂轮廓、突兀的斜线阶梯和无意义孤立像素。
6. **用途验证**：同时看原生尺寸、整数倍放大和实际镜头。生成图可作构图参考，缩小或套马赛克不能代替像素整理。

源色板限制不等于最终限色：光照与混合会产生新颜色。需要严格限色时，在最终输出另做量化，并检查渐变和可读性。

## 按素材类型处理

| 类型 | 绘制与验证要点 |
| --- | --- |
| 建筑分面 | 分别画正面、侧面、屋顶的正交展开；凸出窗台、屋檐用几何。动态打光贴图以较中性的底色为主，避免烘入长投影或强定向光 |
| 地面 | 环绕绘制或偏移画布检查跨边连续性，至少看 3×3 拼铺，再做兼容变体。水洼、落叶和大裂缝作为局部覆盖；有方向或文字的地块不可随意旋转 |
| 植被与岩石 | 先画叶丛剪影或大折面，再点少量纹理。透明平面须检查侧视消失与遮挡；完整绕行的主体使用体积 |
| 小道具 | 优先壶把、箱扣、椅背等识别特征，少量集中高光胜过密集装饰 |

工具无关的小样：制作木箱时，先画一张 32×32 正面，以基色铺底，用窄色带分出边框和两三块板；补少量接缝、顺纹裂痕与箱扣，再按同一密度画侧面和顶面，贴到盒体。换两个光照方向检查体积，别把三面透视先画进一张正面图。

## 角色帧、锚点与动作

先完成站姿母版，再扩展所需方向和动作。各帧保留同一原画布、逻辑落脚锚点与动作余量；裁切导出须保存偏移，不要逐帧裁切后重新居中。非对称装备、文字或持物手需要单独方向图。

步行围绕“接触—承重—经过—推离”设计，左右臂腿反向摆动；跑步重新设计前倾、屈膝、后蹬、摆臂和腾空，不能只加速步行。标出左右脚真实触地的相位；腾空帧允许脚离开锚点。

竖直精灵平面通常只绕竖直轴面向镜头，脚底定位在实际地表。按角色朝向相对镜头的角度选方向帧，方向切换可设置稳定区间；大俯仰需要额外视图或几何方案。

若原画布为 `W×H`、锚点 `(px,py)` 从左上边界向右下测量、密度为 `D`，以锚点为原点且局部向上为正的平面边界为：

```text
left = -px/D          right = (W-px)/D
bottom = (py-H)/D     top = py/D
```

使用单帧原画布尺寸，先恢复图集裁切偏移；若锚点记的是像素格中心，需换成中心坐标。不要把平面中心放在地表，也不要把透明外框当作可见身高。

对于逻辑移动、原地绘制的动画，以接地时相对支撑面的有效路径长度推进相位：`Δphase = Δs/Lcycle`，`Lcycle` 是同一只脚两次触地之间的完整循环距离。跨越触地标记时产生事件，驱动姿态对应的脚步声与表面反馈。低帧率跨多个标记时保留各自时刻；走跑切换保持脚序连续，或明确重置相位与事件游标，避免重复触发。

撞墙、停止、暂停、腾空及平台整体搬运不推进普通行走脚步；滑行与击退使用各自状态。瞬移清理累计值，跳跃落地另发接触事件。动画带根运动时统一位移主导权，不重复叠加。同步节奏后仍要检查支撑脚轨迹与步幅，防止滑步。

## 导出与采样

保留可编辑源文件或绘制配方、色板、原生尺寸无损图片；图集另存帧矩形、原画布与裁切偏移、锚点、帧时长和触地标记。源文件与运行资源可分开存放。

- 区分不透明、硬边裁剪与半透明素材。硬边可从透明裁剪及深度测试/写入起步；半透明按管线处理混合与排序，关闭深度写入并不能解决所有排序问题。
- 底色与带色发光图按实际编码处理颜色空间；法线、粗糙度和数值遮罩按数据图处理。灰度外观不能决定用途，输出颜色转换也要一致。
- 近处像素笔触可用最近邻放大；远景、斜地面与缩小贴图按需求选择 mipmap、各向异性或经过过滤的缩小采样。硬边透明素材需检查缩小后轮廓覆盖率。
- 图集透明留白不等于边缘颜色扩展。过滤和 mipmap 可能混入相邻帧，需要足够隔离、逐级边缘扩展、独立纹理或纹理数组等适合当前引擎的方案，并检查最小显示尺寸。
- 重复整张图集不会只重复某个地块子图；对子图重复需专门处理 UV 与过滤边界，简单场景可优先用独立可平铺纹理。
