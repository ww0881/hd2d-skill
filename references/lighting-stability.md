# 光影与移动稳定性

## 先建立光照层次

按“环境补光 → 主光 → 接触与投影 → 少量焦点光 → 远近层次 → 可选后期”建立画面。明亮场景依靠方向与明暗分区，暗场景仍需可读轮廓；雾、景深、强辉光都不是 HD2D 的必要条件。

自身发光、照亮邻近物体、屏幕辉光分别处理。发光材质未必产生局部照明；辉光只是亮部扩散，不能替代灯光。不要按颜色鲜艳程度自动认定发光，优先使用明确的材质或遮罩。

粗糙度用于支持它的材质模型；湿地不等于金属。自定义倒影不自动继承材质粗糙度。贴图局部遮蔽可保留，强方向烘焙光须与动态灯光协调。

## 闪烁先隔离来源

固定曝光、天气时间、尺寸与移动路线，分别关闭辉光、反射、阴影和动态灯切换，每次只改一项。关闭时间动画后只移动相机，区分预期动态与采样跳变。

| 现象 | 优先排查与处理 |
| --- | --- |
| 无后期仍有细线、纹样爬动 | 亚像素几何、纹理缩小或透明裁剪；减少过细细节，选择合适的缩小过滤，检查实际场景目标的抗锯齿 |
| 加辉光后亮斑突然跳大 | 降采样漏采、硬亮度阈值；先低通过滤，再连续提取亮度 |
| 饱和红蓝边缘比白灯更跳 | 单纯灰度检测漏掉彩色亮边；结合颜色通道峰值和局部对比度 |
| 只有倒影或细波闪 | 反射纹理缩小、投影与波纹频率；按[水面参考](water.md)处理 |
| 两个面交替显露 | 共面深度冲突；调整真实间距、贴花或小幅深度偏移，不用辉光遮盖 |
| 整片照明在位置边界跳变 | 光源数量/选择突变或自动曝光；选择加稳定区间，必要时渐变切换 |
| 阴影随微移跳动 | 投影范围与阴影纹素网格变化；稳定覆盖范围与投影，调整偏移 |

MSAA 主要处理几何覆盖边缘，不自动解决纹理、高光、透明裁剪与后期混叠。离屏渲染要检查实际目标的采样数、颜色/深度格式与解析过程，不能仅看主画布抗锯齿开关；能力不足时提供降级。

## 保留像素笔触的高亮处理

以下用于允许柔和光影的模式；严格屏幕像素输出遵守入口中的最终量化与整数放大约定。

```text
线性 HDR 场景 ──────────────────────────────┐
     └→ 光层输入预过滤 → 软亮度提取 → 过滤缩小与扩散 ─→ 合成
                                                        ↓
                                             色调映射与颜色转换
                                                        ↓
                                             合适的边缘处理 → 界面
```

1. **原场景与光层分离。** 小范围加权过滤只处理辉光输入，避免把墙面纹理和人物一起磨平。设备或管线不支持 HDR 时，明确按可用动态范围调节。
2. **先考虑覆盖率，再做非线性阈值。** 细亮线跨像素运动时，“先随意缩小、再硬截取”容易忽明忽暗。可在完整场景尺寸预过滤并提取亮部，再以低通滤波缩小；放大已经漏采的纹理无法补回信息。
3. **采用软阈值。** 在阈值附近连续增加亮部贡献。预过滤会降低峰值，需联合调整阈值与强度，在固定机位对照平均亮度、颜色和细字；变暗不等于稳定性改善。
4. **兼顾彩色高亮。** 局部边缘处理可用颜色通道峰值辅助灰度判定，限制范围与强度，让暗部像素尽量直通，并检查白衣、细字和叶片是否误柔化。FXAA 改善空间锯齿，不保证时间稳定。
5. **核对颜色空间。** 在线性空间提取、叠加光能。边缘算法按其输入约定放置；需要显示颜色的实现置于输出转换之后，避免重复转换。界面最后独立绘制。
6. **核对最终缩放。** 柔和光晕若再被粗糙的最近邻放大，仍会出现块状跳动；严格像素模式则有意保留最终网格，需接受这种取舍。

不要用简单混合上一帧的方式伪装 TAA。真正时域方案需要运动重投影、遮挡判断、历史拒绝，以及镜头切换和尺寸变化后的历史清理，否则会拖影。已有引擎提供成熟方案时，优先使用其正确配置。

## 动态验证与预算

使用相同路线、速度、曝光和随机条件，覆盖慢速平移、折返、转向，以及远近细亮线。分别观察几何边、透明轮廓、彩色高亮、阴影与水面；用连续帧或视频判断跳变，同时保留静态画面检查像素细节。

对受控目标可测亮度变化幅度，但须同时比较平均亮度与清晰度，不能以压暗或全屏模糊替代修复。记录帧耗时、额外渲染与纹理成本；桌面结果不代表移动设备表现。优先修复已定位的来源，避免无依据叠加所有抗锯齿手段。
