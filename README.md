# HD2D 像素三维场景搭建

一个中文场景制作 skill：用简单三维几何建立空间，以像素素材、镜头和光影塑造观感。适用于游戏、互动插画、空间导览及展示，不限定题材、引擎或平台。

包含两份可离线运行的 HTML demo：**雨港 · 霓虹夜行**与**千里江山 · 画中游**。

## 快速使用

1. 下载并解压仓库或分享包，将文件夹命名为 `hd2d-scene-builder`。
2. 将整个文件夹放入支持 `SKILL.md` 的智能体工具的技能目录。Codex 使用 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/`。
3. 在新会话中使用 `$hd2d-scene-builder`，补充主题、镜头、平台和需要的交互。其他工具的安装与调用方式以其技能机制为准。

例如：

> 使用 $hd2d-scene-builder 制作一个竖屏古风庭院，使用透视镜头，人物可以沿石径行走；先完成素材与构图小样，再扩展布局。

> 使用 $hd2d-scene-builder 检查现有像素三维场景的移动闪烁，保留像素笔触，优先定位问题来源后再调整光影。

无需安装 skill 也可直接阅读 [制作入口](SKILL.md)。它是指导智能体实施的方法集，不是自动生成任意场景的独立软件。

## 校验与重新打包

需要 Python 3.10 或更新版本，仅使用标准库。在仓库根目录运行：

```text
python tools/release.py check
python tools/release.py pack
```

校验覆盖目录结构、包内链接、离线 HTML 的外链依赖、已知本机信息与凭据形状、许可保留。打包命令先校验，再生成 `dist/hd2d-scene-builder.zip`，压缩包内含同名顶层目录。它不会把 Git 记录、缓存、个人配置或旧压缩包打进去。

静态校验不替代实际渲染和设备测试。性能、浏览器支持、移动端显示及音频行为仍需在目标环境验证；样例的解析水纹与粒子不等于完整流体模拟。
