# 两个 HD2D 场景 demo

解压完整分享包后，用支持 WebGL 2 且启用硬件加速的浏览器打开下面任一 HTML。图片、样式、程序及声音资源已内嵌，无需安装开发依赖或连接素材服务；浏览器需在点击声音按钮后才播放音频。

| 样例 | 观察重点 | 主要操作 |
| --- | --- | --- |
| [雨港 · 霓虹夜行](雨港.html) | 方盒建筑与透视街景、像素角色、霓虹光影、积水倒影、走跑水花 | WASD / 方向键行走，Shift 跑步，点击路面前往，右键拖动环视，滚轮缩放，E 互动 |
| [千里江山 · 画中游](千里江山.html) | 青绿山水、山体与亭桥、植被、水岸映色、晨暮变化及景物互动 | A / D 或左右方向键行走，Shift 疾行，空格跳跃，E 互动，点击古道或路线地点前往 |

两个样例都提供页面上的声音和触摸操作按钮，Esc 暂停或关闭弹窗。千里江山推荐横屏，可沿古道连续走到下卷，用顶栏切换晨光与暮色。雨港可在底栏切换走跑与雨幕。

样例展示的是不同主题下的具体取舍，参数不作为通用标准。雨港的城市故事保留于当前打开期间；千里江山的游记在浏览器允许时使用本地存储。两者的水纹和粒子都是视觉近似，不包含完整流体模拟。

这两份 HTML 是可独立运行的成品快照，分享包不包含原项目的完整开发工程。新建场景按 [SKILL.md](../../SKILL.md) 及其参考文档选择结构、素材和效果，不必先复刻样例。
